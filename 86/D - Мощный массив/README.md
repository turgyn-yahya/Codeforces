<div class="header"><div class="title">D. Мощный массив</div><div class="time-limit"><div class="property-title">ограничение по времени на тест</div>5 seconds</div><div class="memory-limit"><div class="property-title">ограничение по памяти на тест</div>256 megabytes</div><div class="input-file input-standard" style="font-weight: bold"><div class="property-title">ввод</div>stdin</div><div class="output-file output-standard" style="font-weight: bold"><div class="property-title">вывод</div>stdout</div></div><div><p>Имеется массив натуральных чисел <span class="tex-span"><i>a</i><sub class="lower-index">1</sub>, <i>a</i><sub class="lower-index">2</sub>, ..., <i>a</i><sub class="lower-index"><i>n</i></sub></span>. Рассмотрим некоторый его подмассив <span class="tex-span"><i>a</i><sub class="lower-index"><i>l</i></sub>, <i>a</i><sub class="lower-index"><i>l</i> + 1</sub>, ..., <i>a</i><sub class="lower-index"><i>r</i></sub></span>, где <span class="tex-span">1 ≤ <i>l</i> ≤ <i>r</i> ≤ <i>n</i></span>, и для каждого натурального числа <span class="tex-span"><i>s</i></span> обозначим через <span class="tex-span"><i>K</i><sub class="lower-index"><i>s</i></sub></span> число вхождений числа <span class="tex-span"><i>s</i></span> в этот подмассив. Назовем <span class="tex-font-style-it">мощностью</span> подмассива сумму произведений <span class="tex-span"><i>K</i><sub class="lower-index"><i>s</i></sub>·<i>K</i><sub class="lower-index"><i>s</i></sub>·<i>s</i></span> по всем различным натуральным <span class="tex-span"><i>s</i></span>. Так как количество различных чисел в массиве конечно, сумма содержит лишь конечное число ненулевых слагаемых.</p><p>Необходимо вычислить мощности каждого из <span class="tex-span"><i>t</i></span> заданных подмассивов.</p></div><div class="input-specification"><div class="section-title">Входные данные</div><p>Первая строка содержит два целых числа <span class="tex-span"><i>n</i></span> и <span class="tex-span"><i>t</i></span> (<span class="tex-span">1 ≤ <i>n</i>, <i>t</i> ≤ 200000</span>) — длина массива и количество запросов соответственно.</p><p>Вторая строка содержит <span class="tex-span"><i>n</i></span> натуральных чисел <span class="tex-span"><i>a</i><sub class="lower-index"><i>i</i></sub></span> (<span class="tex-span">1 ≤ <i>a</i><sub class="lower-index"><i>i</i></sub> ≤ 10<sup class="upper-index">6</sup></span>) — элементы массива.</p><p>Следующие <span class="tex-span"><i>t</i></span> строк содержат по два натуральных числа <span class="tex-span"><i>l</i></span> и <span class="tex-span"><i>r</i></span> (<span class="tex-span">1 ≤ <i>l</i> ≤ <i>r</i> ≤ <i>n</i></span>) — индексы левого и правого концов соответствующего подмассива.</p></div><div class="output-specification"><div class="section-title">Выходные данные</div><p>Выведите <span class="tex-span"><i>t</i></span> строк, где <span class="tex-span"><i>i</i></span>-ая строка содержит единственное натуральное число — мощность подмассива <span class="tex-span"><i>i</i></span>-го запроса.</p><p>Пожалуйста, не используйте спецификатор <span class="tex-font-style-tt">%lld</span> для чтения или записи 64-х битовых чисел на С++. Рекомендуется использовать поток <span class="tex-font-style-tt">cout</span> (также вы можете использовать спецификатор <span class="tex-font-style-tt">%I64d</span>).</p></div><div
