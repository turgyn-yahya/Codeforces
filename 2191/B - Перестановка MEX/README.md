<h3><a href="https://codeforces.com/contest/2191/problem/B" target="_blank" rel="noopener noreferrer">Перестановка MEX</a></h3>

<div class="header"><div class="title">B. Перестановка MEX</div><div class="time-limit"><div class="property-title">ограничение по времени на тест</div>1 секунда</div><div class="memory-limit"><div class="property-title">ограничение по памяти на тест</div>256 мегабайт</div><div class="input-file input-standard"><div class="property-title">ввод</div>стандартный ввод</div><div class="output-file output-standard"><div class="property-title">вывод</div>стандартный вывод</div></div><div><p>  </p><p>Дан массив целых чисел $$$a$$$, состоящий из $$$n$$$ элементов. Обозначим $$$f(l, r) = \operatorname{MEX}([a_l, a_{l + 1}, \ldots, a_r])$$$$$$^{\text{∗}}$$$. </p><p>Определите, существует ли способ переставить массив $$$a$$$ так, чтобы для <span class="tex-font-style-bf">каждого</span> $$$i$$$ ($$$1 \le i \le n - 1$$$) выполнялось $$$f(1, i) \neq f(i + 1, n)$$$. Другими словами, для каждой точки разбиения $$$i$$$ значение $$$\operatorname{MEX}$$$ префикса должно отличаться от значения $$$\operatorname{MEX}$$$ суффикса.</p><div class="statement-footnote"><p>$$$^{\text{∗}}$$$Наименьшее исключенное (MEX) набора чисел $$$c_1, c_2, \ldots, c_k$$$ определяется как наименьшее неотрицательное целое число $$$x$$$, которое не встречается в наборе чисел $$$c$$$. </p></div></div><div class="input-specification"><div class="section-title">Входные данные</div><p>Каждый тест состоит из нескольких наборов входных данных. В первой строке находится одно целое число $$$t$$$ ($$$1 \le t \le 500$$$) — количество наборов входных данных. Далее следует описание наборов входных данных. </p><p>Первая строка каждого набора входных данных содержит одно целое число $$$n$$$ ($$$2 \le n \le 100$$$) — длина массива.</p><p>Вторая строка каждого набора входных данных содержит $$$n$$$ целых чисел $$$a_1, a_2, \ldots, a_n$$$ ($$$0 \le a_i \le n$$$).</p></div><div class="output-specification"><div class="section-title">Выходные данные</div><p>Выведите «<span class="tex-font-style-tt">YES</span>» если вы можете переставить $$$a$$$ так, чтобы условие из задачи было выполнено, и «<span class="tex-font-style-tt">NO</span>» в противном случае. Вы можете выводить каждую букву в любом регистре (строчную или заглавную). Например, строки «<span class="tex-font-style-tt">yEs</span>», «<span class="tex-font-style-tt">yes</span>», «<span class="tex-font-style-tt">Yes</span>» и «<span class="tex-font-style-tt">YES</span>» будут приняты как положительный ответ. </p></div><div class="sample-tests"><div class="section-title">Пример</div><div class="sample-test"><div class="input"><div class="title">Входные данные<div title="Скопировать" data-clipboard-target="#id004440835912875005" id="id006094794674720111" class="input-output-copier">Скопировать</div></div><pre id="id004440835912875005"><div class="test-example-line test-example-line-even test-example-line-0">3</div><div class="test-example-line test-example-line-odd test-example-line-1">2</div><div class="test-example-line test-example-line-odd test-example-line-1">1 0</div><div class="test-example-line test-example-line-even test-example-line-2">3</div><div class="test-example-line test-example-line-even test-example-line-2">0 3 0</div><div class="test-example-line test-example-line-odd test-example-line-3">6</div><div class="test-example-line test-example-line-odd test-example-line-3">1 0 5 0 6 1</div></pre></div><div class="output"><div class="title">Выходные данные<div title="Скопировать" data-clipboard-target="#id005069585351190029" id="id00006999624901059542" class="input-output-copier">Скопировать</div></div><pre id="id005069585351190029"><div class="test-example-line test-example-line-odd test-example-line-1">YES</div><div class="test-example-line test-example-line-even test-example-line-2">NO</div><div class="test-example-line test-example-line-odd test-example-line-3">YES</div></pre></div></div></div><div class="note"><div class="section-title">Примечание</div><p>В первом наборе входных данных начальный порядок $$$a$$$ уже удовлетворяет условию. Единственный выбор для $$$i$$$ — это $$$i = 1$$$. Тогда $$$f(1, i) = f(1, 1) = \operatorname{MEX}([a_1]) = \operatorname{MEX}([1]) = 0$$$, и $$$f(i + 1, n) = f(2, 2) = \operatorname{MEX}([a_2]) = \operatorname{MEX}([0]) = 1$$$. Поскольку $$$0 \neq 1$$$, условие выполнено.</p><p>Во втором наборе входных данных можно показать, что нет способа переставить $$$a$$$, чтобы удовлетворить условию. Например, рассмотрим порядок $$$a = [3, 0, 0]$$$ и $$$i = 2$$$. Мы имеем $$$f(1, i) = f(1, 2) = \operatorname{MEX}([a_1, a_2]) = \operatorname{MEX}([3, 0]) = 1$$$, и $$$f(i + 1, n) = f(3, 3) = \operatorname{MEX}([a_3]) = \operatorname{MEX}([0]) = 1$$$, следовательно, $$$f(1, i) = f(i + 1, n)$$$, так что выбор перестановки некорректен.</p><p>В третьем наборе входных данных мы можем переставить $$$a$$$ в $$$[1, 6, 1, 0, 0, 5]$$$. Когда $$$i = 4$$$, $$$f(1, i) = f(1, 4) = \operatorname{MEX}([a_1, a_2, a_3, a_4]) = \operatorname{MEX}([1, 6, 1, 0]) = 2$$$, $$$f(i + 1, n) = f(5, 6) = \operatorname{MEX}([a_5, a_6]) = \operatorname{MEX}([0, 5]) = 1$$$, так что условие выполнено для этого $$$i$$$. Можно проверить, что условие также выполнено для всех других $$$i$$$.</p></div>
