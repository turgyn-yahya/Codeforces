Эта операция стоит $$$1$$$ монету; </li><li> поменять местами любую пару символов в $$$s$$$. Эта операция бесплатна (стоит $$$0$$$ монет). </li></ol><p>Вы можете выполнять эти операции в любом порядке любое количество раз.</p><p>Давайте обозначим строку, которую вы получили после выполнения вышеуказанных операций, как $$$t$$$. Строка $$$t$$$ является <span class="tex-font-style-it">хорошей</span>, если для каждого $$$i$$$ от <span class="tex-font-style-bf">$$$1$$$ до $$$|t|$$$</span> $$$t_i \neq s_i$$$ ($$$|t|$$$ — длина строки $$$t$$$). Пустая строка — <span class="tex-font-style-it">всегда хорошая</span>. Обратите внимание, что вы сравниваете результирующую строку $$$t$$$ с <span class="tex-font-style-it">исходной строкой</span> $$$s$$$.</p><p>Какова минимальная суммарная стоимость сделать строку $$$t$$$ хорошей?</p></div><div class="input-specification"><div class="section-title">Входные данные</div><p>Первая строка содержит одно целое число $$$t$$$ ($$$1 \le t \le 10^4$$$) — количество наборов входных данных. Далее следуют $$$t$$$ наборов входных данных.</p><p>В единственной строке каждого набора задана бинарная строка $$$s$$$ ($$$1 \le |s| \le 2 \cdot 10^5$$$; $$$s_i \in \{$$$<span class="tex-font-style-tt">0</span>, <span class="tex-font-style-tt">1</span>$$$\}$$$) — исходная строка, состоящая из символов <span class="tex-font-style-tt">0</span> и/или <span class="tex-font-style-tt">1</span>.</p><p>Дополнительное ограничение на входные данные: общая длина всех строк $$$s$$$ не превышает $$$2 \cdot 10^5$$$.</p></div><div class="output-specification"><div class="section-title">Выходные данные</div><p>Для каждого набора входных данных выведите минимальную суммарную стоимость сделать строку $$$t$$$ хорошей.</p></div><div class="sample-tests"><div class="section-title">Пример</div><div class="sample-test"><div class="input"><div class="title">Входные данные<div title="Скопировать" data-clipboard-target="#id00568092712699607" id="id00516558592770653" class="input-output-copier">Скопировать</div></div><pre id="id00568092712699607"><div class="test-example-line test-example-line-even test-example-line-0">4</div><div class="test-example-line test-example-line-odd test-example-line-1">0</div><div class="test-example-line test-example-line-even test-example-line-2">011</div><div class="test-example-line test-example-line-odd test-example-line-3">0101110001</div><div class="test-example-line test-example-line-even test-example-line-4">111100</div></pre></div><div class="output"><div class="title">Выходные данные<div title="Скопировать" data-clipboard-target="#id002966593127386904" id="id0072485029243575" class="input-output-copier">Скопировать</div></div><pre id="id002966593127386904">1
