Необходимо найти максимальную длину подотрезка, состоящего из одинаковых значений, среди всех массивов $$$c$$$, которые можно получить.</p><p>$$$^\dagger$$$ В результате объединения двух массивов получается массив $$$c$$$, составленный путем последовательного взятия первого элемента любого из массивов (если этот массив не пуст) и его удаления. После этого элемент добавляется в конец массива $$$c$$$.
