<div class="header"><div class="title">D. Нечётные запросы</div><div class="time-limit"><div class="property-title">ограничение по времени на тест</div>2 секунды</div><div class="memory-limit"><div class="property-title">ограничение по памяти на тест</div>256 мегабайт</div><div class="input-file input-standard"><div class="property-title">ввод</div>стандартный ввод</div><div class="output-file output-standard"><div class="property-title">вывод</div>стандартный вывод</div></div><div><p>У вас есть массив $$$a_1, a_2, \dots, a_n$$$. Ответьте на $$$q$$$ таких запросов:</p><ul> <li> Если сделать каждый элемент подотрезка массива $$$a_l, a_{l+1}, \dots, a_r$$$ равным $$$k$$$, будет ли сумма всего массива нечетной? </li></ul><p>Обратите внимание, что запросы <span class="tex-font-style-bf">независимы</span> и не влияют на будущие запросы.</p></div><div class="input-specification"><div class="section-title">Входные данные</div><p>Каждый тест состоит из нескольких наборов входных данных. Первая строка содержит количество наборов входных данных $$$t$$$ ($$$1 \le t \le 10^4$$$). Далее следует описание наборов входных данных.</p><p>Первая строка каждого набора входных данных содержит $$$2$$$ целых числа $$$n$$$ и $$$q$$$ ($$$1 \le n \le 2 \cdot 10^5$$$; $$$1 \le q \le 2 \cdot 10^5$$$) — длина массива и количество запросов.</p><p>Вторая строка каждого набора входных данных содержит $$$n$$$ целых чисел $$$a_i$$$ ($$$1 \le a_i \le 10^9$$$) — массив $$$a$$$.</p><p>Следующие $$$q$$$ строк содержат по $$$3$$$ целых числа $$$l,r,k$$$ ($$$1 \le l \le r \le n$$$; $$$1 \le k \le 10^9$$$) — запросы.</p><p>Гарантируется, что сумма $$$n$$$ по всем наборам входных данных не превышает $$$2 \cdot 10^5$$$ и сумма $$$q$$$ не превышает $$$2 \cdot 10^5$$$.</p></div><div class="output-specification"><div class="section-title">Выходные данные</div><p>Для каждого запроса выведите «<span class="tex-font-style-tt">YES</span>», если сумма всего массива будет нечетной, и «<span class="tex-font-style-tt">NO</span>» в противном случае.</p><p>Вы можете выводить каждую букву в любом регистре (строчную или заглавную). Например, строки «<span class="tex-font-style-tt">yEs</span>», «<span class="tex-font-style-tt">yes</span>», «<span class="tex-font-style-tt">Yes</span>» и «<span class="tex-font-style-tt">YES</span>»
