Выпуклая фигура</div><div class="time-limit"><div class="property-title">ограничение по времени на тест</div>2 секунды</div><div class="memory-limit"><div class="property-title">ограничение по памяти на тест</div>256 мегабайт</div><div class="input-file input-standard" style="font-weight: bold"><div class="property-title">ввод</div>stdin</div><div class="output-file output-standard" style="font-weight: bold"><div class="property-title">вывод</div>stdout</div></div><div><p>Рассмотрим таблицу размера <span class="tex-span"><i>n</i> × <i>m</i></span>. Изначально все ячейки таблицы закрашены белым цветом. Ленни закрасил некоторые из ячеек (по красней мере, одну) черным. Назовем таблицу <span class="tex-font-style-underline">выпуклой</span>, если можно пройти от <span class="tex-font-style-bf">любой</span> черной ячейки до <span class="tex-font-style-bf">любой другой</span> черной ячейки (разрешено переходить с ячейки на любую из соседних по стороне черных ячеек), изменяя направление не больше одного раза на протяжении пути. На картинке ниже левая таблица выпуклая, а правая — нет, поскольку существуют две ячейки, путь между которыми в любом случае требует более одного изменения направления движения.</p><center> <img class="tex-graphics" src="https://espresso.codeforces.com/fc2c58647ae533843a9d2aa4a1f61fd76fabfec6.png" style="max-width: 100.0%;max-height: 100.0%;"> </center><p>Во входных данных задана таблица. В каждой из следующих <span class="tex-span"><i>n</i></span> строк содержится по <span class="tex-span"><i>m</i></span> символов «<span class="tex-font-style-tt">B</span>» или «<span class="tex-font-style-tt">W</span>». Символ «<span class="tex-font-style-tt">B</span>» обозначает черную ячейку таблицы, а «<span class="tex-font-style-tt">W</span>» обозначает белую ячейку таблицы.</p><p>Гарантируется, что в таблице содержится хотя бы одна черная ячейка.</p></div><div class="output-specification"><div class="section-title">Выходные данные</div><p>В единственной строке выходных данных выведите «<span class="tex-font-style-tt">YES</span>», если таблица выпуклая, в противном случае выведите «<span class="tex-font-style-tt">NO</span>».
