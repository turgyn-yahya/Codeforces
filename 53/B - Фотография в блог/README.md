Он вырезает из них прямоугольную область так, чтобы отношение высоты к ширине (т. е. частное <span class="tex-span"><i>высота</i> / <i>ширина</i></span>) находилось в границах от 0.8 до 1.25 включительно. Кроме того, хотя бы одна из сторон вырезанной части должны иметь размер, равный некоторой степени числа 2 (<span class="tex-span">2<sup class="upper-index"><i>x</i></sup></span> для некоторого целого числа <span class="tex-span"><i>x</i></span>). Разумеется, обе стороны вырезаемой части должны быть целочисленными.
