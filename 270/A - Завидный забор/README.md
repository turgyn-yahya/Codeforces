Так что юноша приобрел робота-заборостройщика.</p><p>Эмускальду хочется, чтобы забор представлял собой правильный многоугольник. К сожалению, его робот строит забор, двигаясь по единственному пути. При этом робот может соединять стороны забора только под заданным углом <span class="tex-span"><i>a</i></span>.</p><p>Сможет ли робот построить забор, который хочет Эмускальд?
