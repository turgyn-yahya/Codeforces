Поэтому она попросила Диму написать небольшое число, состоящее из девяток. Но Дима, видимо, что-то перепутал и написал очень большое число <span class="tex-span"><i>a</i></span>, состоящее из цифр от <span class="tex-span">1</span> до <span class="tex-span">9</span>.</p><p>Инна хочет немного поменять число, написанное Димой, чтобы в итоге число содержало как можно больше девяток. За один ход Инна может взять две соседние цифры в числе, сумма которых равна <span class="tex-span">9</span>, и заменить их на одну цифру <span class="tex-span">9</span>.</p><p>Например, Инна может изменить число <span class="tex-span">14545181</span> следующим образом: <span class="tex-span">14545181 → 1945181 → 194519 → 19919</span>. Также из числа <span class="tex-span">14545181</span> описанным способом можно получить число <span class="tex-span">19991</span>. Число <span class="tex-span">149591</span> Инна получать не станет, поскольку можно получить числа <span class="tex-span">19919</span> и <span class="tex-span">19991</span>, а они содержат больше девяток.</p><p>Дима — программист, поэтому он хочет узнать сколько различных чисел с максимальным количеством девяток может получить Инна из записанного им числа.
