Все камни Курияма Мираи пронумерованы от <span class="tex-span">1</span> до <span class="tex-span"><i>n</i></span>. Курияма Мираи хочет узнать некоторую информацию о своих камнях, с этой целью она задает вам вопросы. Каждый вопрос имеет один из следующих видов:</p><ol> <li> Она называет вам два числа, <span class="tex-span"><i>l</i></span> и <span class="tex-span"><i>r</i> (1 ≤ <i>l</i> ≤ <i>r</i> ≤ <i>n</i>)</span>, а вы должны сказать ей, чему равна сумма <img align="middle" class="tex-formula" src="https://espresso.codeforces.com/6a950b27de2103bb53df10f9ace817ae3df57fa9.png" style="max-width: 100.0%;max-height: 100.0%;">. </li><li> Пусть <span class="tex-span"><i>u</i><sub class="lower-index"><i>i</i></sub></span> равняется цене <span class="tex-span"><i>i</i></span>-го по дешевизне камня (цена, которая будет на <span class="tex-span"><i>i</i></span>-ом месте, если расположить все цены камней в порядке неубывания). На этот раз она называет вам два числа, <span class="tex-span"><i>l</i></span> и <span class="tex-span"><i>r</i> (1 ≤ <i>l</i> ≤ <i>r</i> ≤ <i>n</i>)</span>, а вы должны сказать ей, чему равна сумма <img align="middle" class="tex-formula" src="https://espresso.codeforces.com/9830c0af1b3d14c66843c32f7c106c97428b7d2d.png" style="max-width: 100.0%;max-height: 100.0%;">. </li></ol><p>Вам нужно ответить правильно на ее вопросы, или Курияма Мираи скажет «fuyukai desu» (яп. неприятно) и расстроится.</p></div><div class="input-specification"><div class="section-title">Входные данные</div><p>В первой строке записано целое число <span class="tex-span"><i>n</i> (1 ≤ <i>n</i> ≤ 10<sup class="upper-index">5</sup>)</span>. Во второй строке записано <span class="tex-span"><i>n</i></span> целых чисел: <span class="tex-span"><i>v</i><sub class="lower-index">1</sub>, <i>v</i><sub class="lower-index">2</sub>, ..., <i>v</i><sub class="lower-index"><i>n</i></sub> (1 ≤ <i>v</i><sub class="lower-index"><i>i</i></sub> ≤ 10<sup class="upper-index">9</sup>)</span> – цены камней. </p><p>В третьей строке записано целое число <span class="tex-span"><i>m</i> (1 ≤ <i>m</i> ≤ 10<sup class="upper-index">5</sup>)</span> — количество вопросов Курияма Мираи.
