И Вася решил за это время улучшить свои навыки программирования, а также позаниматься спортом. Про каждый из <span class="tex-span"><i>n</i></span> дней каникул Вася знает, будет ли открыт в этот день спортзал, а также будет ли в интернете в этот день проводиться контест. Для <span class="tex-span"><i>i</i></span>-го дня возможны четыре варианта:</p><ol> <li> в этот день закрыт спортзал и не проводится контест; </li><li> в этот день закрыт спортзал и проводится контест; </li><li> в этот день открыт спортзал и не проводится контест; </li><li> в этот день открыт спортзал и проводится контест. </li></ol><p>В каждый из дней Вася может либо отдыхать, либо писать контест (если он проводится в этот день), либо заниматься спортом (если открыт спортзал).</p><p>Перед вами стоит задача найти минимальное количество дней, в которые Вася будет отдыхать (то есть не будет заниматься спортом и не будет писать контест одновременно). Единственное ограничение от Васи — <span class="tex-font-style-it">он не хочет два дня подряд заниматься одним и тем же видом активности, то есть он не будет заниматься спортом два дня подряд и он не будет писать контесты два дня подряд</span>.</p></div><div class="input-specification"><div class="section-title">Входные данные</div><p>В первой строке следует целое положительное число <span class="tex-span"><i>n</i></span> (<span class="tex-span">1 ≤ <i>n</i> ≤ 100</span>) — количество дней в каникулах Васи.</p><p>Во второй строке следует через пробел последовательность целых чисел <span class="tex-span"><i>a</i><sub class="lower-index">1</sub>, <i>a</i><sub class="lower-index">2</sub>, ..., <i>a</i><sub class="lower-index"><i>n</i></sub></span> (<span class="tex-span">0 ≤ <i>a</i><sub class="lower-index"><i>i</i></sub> ≤ 3</span>), где: </p><ul> <li> <span class="tex-span"><i>a</i><sub class="lower-index"><i>i</i></sub></span> равно 0, если в <span class="tex-span"><i>i</i></span>-й день каникул не работает спортзал и не проводится контест; </li><li> <span class="tex-span"><i>a</i><sub class="lower-index"><i>i</i></sub></span> равно 1, если в <span class="tex-span"><i>i</i></span>-й день каникул не работает спортзал, но проводится контест; </li><li> <span class="tex-span"><i>a</i><sub class="lower-index"><i>i</i></sub></span> равно 2, если в <span class="tex-span"><i>i</i></span>-й день каникул работает спортзал и не проводится контест; </li><li> <span class="tex-span"><i>a</i><sub class="lower-index"><i>i</i></sub></span> равно 3, если в <span class="tex-span"><i>i</i></span>-й день каникул работает спортзал и проводится контест.</li></ul></div><div class="output-specification"><div class="section-title">Выходные данные</div><p>Выведите минимально возможное количество дней, в которые Вася будет отдыхать.
