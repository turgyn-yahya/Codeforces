Определим две операции, которые можно применить к строке:</p><ul> <li> удалить первый символ строки; </li><li> удалить второй символ строки. </li></ul><p>Ваша задача — найти количество различных <span class="tex-font-style-bf">непустых</span> строк, которые можно получить, применяя заданные операции над исходной строкой любое количество раз (возможно, нулевое), в любом порядке.</p></div><div class="input-specification"><div class="section-title">Входные данные</div><p>Каждый тест состоит из нескольких наборов входных данных.
