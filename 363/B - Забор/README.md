Забор</div><div class="time-limit"><div class="property-title">ограничение по времени на тест</div>1 секунда</div><div class="memory-limit"><div class="property-title">ограничение по памяти на тест</div>256 мегабайт</div><div class="input-file input-standard" style="font-weight: bold"><div class="property-title">ввод</div>stdin</div><div class="output-file output-standard" style="font-weight: bold"><div class="property-title">вывод</div>stdout</div></div><div><p>Перед домом Поликарпа находится забор, который состоит из <span class="tex-span"><i>n</i></span> одинаковых по ширине досок, расположенных одна за другой слева направо. Высота <span class="tex-span"><i>i</i></span>-ой доски составляет <span class="tex-span"><i>h</i><sub class="lower-index"><i>i</i></sub></span> метров, разные доски могут иметь различные высоты.</p><center> <img class="tex-graphics" src="https://espresso.codeforces.com/ff4898e61fdca3713f04ee1d3db5a83ac2b3ebcd.png" style="max-width: 100.0%;max-height: 100.0%;">   <span class="tex-font-size-small">Забор для <span class="tex-span"><i>n</i> = 7</span> и <span class="tex-span"><i>h</i> = [1, 2, 6, 1, 1, 7, 1]</span></span> </center><p>Поликарп приобрел рояль и теперь ищет наилучший способ занести рояль в свой дом. Для того, чтобы осуществить задуманное, ему придется выломать ровно <span class="tex-span"><i>k</i></span> подряд идущих досок в заборе. Так как высокие доски выламывать сложнее, Поликарп хочет найти такие <span class="tex-span"><i>k</i></span> последовательных досок, что сумма их высот минимальна.</p><p>Напишите программу, которая найдет номера <span class="tex-span"><i>k</i></span> последовательных досок с наименьшей суммой высот. Обратите внимание, забор не окружает дом Поликарпа, а находится перед ним (другими словами, забор не зациклен).</p></div><div class="input-specification"><div class="section-title">Входные данные</div><p>В первой строке входных данных содержатся целые числа <span class="tex-span"><i>n</i></span> и <span class="tex-span"><i>k</i></span> (<span class="tex-span">1 ≤ <i>n</i> ≤ 1.5·10<sup class="upper-index">5</sup>, 1 ≤ <i>k</i> ≤ <i>n</i></span>) — количество досок в заборе и ширина проема для рояля. Вторая строка содержит последовательность целых чисел <span class="tex-span"><i>h</i><sub class="lower-index">1</sub>, <i>h</i><sub class="lower-index">2</sub>, ..., <i>h</i><sub class="lower-index"><i>n</i></sub></span> (<span class="tex-span">1 ≤ <i>h</i><sub class="lower-index"><i>i</i></sub> ≤ 100</span>), где <span class="tex-span"><i>h</i><sub class="lower-index"><i>i</i></sub></span> — высота <span class="tex-span"><i>i</i></span>-ой доски забора.</p></div><div class="output-specification"><div class="section-title">Выходные данные</div><p>Выведите такое <span class="tex-span"><i>j</i></span>, что сумма высот досок <span class="tex-span"><i>j</i></span>, <span class="tex-span"><i>j</i> + 1</span>, ..., <span class="tex-span"><i>j</i> + <i>k</i> - 1</span> — наименьшая возможная. Если таких <span class="tex-span"><i>j</i></span> несколько, то выведите любое из них.</p></div><div class="sample-tests"><div class="section-title">Примеры</div><div class="sample-test"><div class="input"><div class="title">Входные данные<div title="Скопировать" data-clipboard-target="#id0036923971938305455" id="id0039560510756986167" class="input-output-copier">Скопировать</div></div><pre id="id0036923971938305455">7 3<br>1 2 6 1 1 7 1<br></pre></div><div class="output"><div class="title">Выходные данные<div title="Скопировать" data-clipboard-target="#id009888930375024726" id="id009726725374938827" class="input-output-copier">Скопировать</div></div><pre id="id009888930375024726">3<br></pre></div></div></div><div class="note"><div class="section-title">Примечание</div><p>В примере требуется найти три последовательные доски с минимальной суммой высот.
