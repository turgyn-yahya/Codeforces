Он сделает следующую операцию с данным массивом <span class="tex-font-style-bf">ровно один раз</span>:</p><ul> <li> Выбрать подотрезок массива и циклически сдвинуть его на любую величину. </li></ul> Формально, он может сделать следующее ровно один раз:<ul> <li> Выбрать целые числа $$$l$$$ и $$$r$$$ такие, что $$$1 \le l \le r \le n$$$ и любое целое неотрицательное число $$$k$$$. </li><li> Повторить $$$k$$$ раз: установить $$$a_l=a_{l+1}, a_{l+1}=a_{l+2}, \ldots, a_{r-1}=a_r, a_r=a_l$$$ (все изменения происходят одновременно). </li></ul><p>Mainak хочет <span class="tex-font-style-bf">максимизировать</span> значение $$$(a_n - a_1)$$$ после применения ровно одной такой операции.
