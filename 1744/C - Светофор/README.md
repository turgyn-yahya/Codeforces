<h3><a href="https://codeforces.com/contest/1744/problem/C" target="_blank" rel="noopener noreferrer">Светофор</a></h3>

<div class="header"><div class="title">C. Светофор</div><div class="time-limit"><div class="property-title">ограничение по времени на тест</div>1 секунда</div><div class="memory-limit"><div class="property-title">ограничение по памяти на тест</div>256 мегабайт</div><div class="input-file input-standard"><div class="property-title">ввод</div>стандартный ввод</div><div class="output-file output-standard"><div class="property-title">вывод</div>стандартный вывод</div></div><div><p>Вы попали на необычный перекресток со странным светофором. У этого светофора есть три возможных цвета: красный (<span class="tex-font-style-tt">r</span>), желтый (<span class="tex-font-style-tt">y</span>), зеленый (<span class="tex-font-style-tt">g</span>). Известно, что светофор повторяет свои цвета каждые $$$n$$$ секунд и в $$$i$$$-ю секунду горит цвет $$$s_i$$$.</p><p>Таким образом, порядок цветов задаётся строкой. Например, если $$$s=$$$«<span class="tex-font-style-tt">rggry</span>», то светофор горит так: красный-зеленый-зеленый-красный-желтый-красный-зеленый-зеленый-красный-желтый- ... и так далее.</p><p>Более формально, вам дана строка $$$s_1, s_2, \ldots, s_n$$$ длины $$$n$$$. В первую секунду горит цвет $$$s_1$$$, во вторую $$$s_2$$$, ..., в $$$n$$$-ю секунду горит цвет $$$s_n$$$, в $$$n + 1$$$-ю секунду горит цвет $$$s_1$$$ и так далее.</p><p>Вам нужно перейти дорогу, и это можно сделать только тогда, когда на светофоре горит зеленый цвет. </p><p>Вам известно, какой сейчас цвет на светофоре, но вы не знаете текущей момент времени. Вам нужно найти минимальное время, в течение которого вы точно (наверняка) сможете перейти дорогу.</p><p>Можно считать, что дорогу мы проходим моментально. </p><p>Например, в случае $$$s=$$$«<span class="tex-font-style-tt">rggry</span>» и текущего света <span class="tex-font-style-tt">r</span> возможны два варианта: либо зеленый свет наступит через через $$$1$$$ секунду, либо через $$$3$$$. Таким образом, ответ равен $$$3$$$ — именно через столько секунд мы гарантированно сможем перейти дорогу, если текущий цвет <span class="tex-font-style-tt">r</span>.</p></div><div class="input-specification"><div class="section-title">Входные данные</div><p>В первой строке входных данных дано единственное целое число $$$t$$$ $$$(1 \leq t \leq 10^4$$$) — количество наборов входных данных.</p><p>Далее следуют описания наборов входных данных.</p><p>В первой строке каждого набора входных данных содержится целое число $$$n$$$ и символ $$$c$$$ ($$$1 \leq n \leq 2 \cdot 10^5$$$, $$$c$$$ является одним из допустимых цветов светофора <span class="tex-font-style-tt">r</span>, <span class="tex-font-style-tt">y</span> или <span class="tex-font-style-tt">g</span>)— длина строки $$$s$$$ и текущий цвет светофора. </p><p>Во второй строке каждого набора входных данных содержится строка $$$s$$$ длины $$$n$$$, состоящая из символов <span class="tex-font-style-tt">r</span>, <span class="tex-font-style-tt">y</span> и <span class="tex-font-style-tt">g</span>.</p><p>Гарантируется, что символ <span class="tex-font-style-tt">g</span> встречается в строке $$$s$$$ и что символ $$$c$$$ встречается в строке $$$s$$$. </p><p>Гарантируется, что сумма значений $$$n$$$ по всем наборам входных данных теста не превосходит $$$2\cdot10^5$$$.</p></div><div class="output-specification"><div class="section-title">Выходные данные</div><p>Для каждого набора входных данных выведите минимальное количество секунд, в течение которого можно гарантировано перейти
