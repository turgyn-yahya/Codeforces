Сдвинутый MEX</div><div class="time-limit"><div class="property-title">ограничение по времени на тест</div>2 секунды</div><div class="memory-limit"><div class="property-title">ограничение по памяти на тест</div>256 мегабайт</div><div class="input-file input-standard"><div class="property-title">ввод</div>стандартный ввод</div><div class="output-file output-standard"><div class="property-title">вывод</div>стандартный вывод</div></div><div><p>Вам дан массив из $$$n$$$ целых чисел $$$a_1, a_2, \ldots, a_n$$$. Вам разрешено выполнить следующую операцию один раз. </p><ul> <li> Выберите целое число $$$x$$$ (которое может быть отрицательным), и для каждого значения $$$i$$$ $$$(1 \leq i \leq n)$$$ присвойте $$$a_i = a_i + x$$$. </li></ul><p>Например, если $$$a = [1, 3, 4, 2]$$$, и вы выполните операцию с $$$x = 3$$$, то $$$a$$$ теперь равен $$$[4, 6, 7, 5]$$$.</p><p>Выведите максимальное возможное значение $$$\operatorname{MEX}(a)$$$$$$^{\text{∗}}$$$ после выполнения операции.</p><div class="statement-footnote"><p>$$$^{\text{∗}}$$$$$$\operatorname{MEX}(a)$$$ определяется как наименьшее неотрицательное целое число, которое отсутствует в массиве. Например, $$$\operatorname{MEX}([1, 2, 0, 5])$$$ равно $$$3$$$, а $$$\operatorname{MEX}([1, 2, 4, 9])$$$ равно $$$0$$$.</p></div></div><div class="input-specification"><div \le 10^9$$$) — массив $$$a$$$.</p><p>Гарантируется, что сумма $$$n$$$ по всем наборам входных данных не превышает $$$3000$$$.</p></div><div class="output-specification"><div
