<h3><a href="https://codeforces.com/contest/1759/problem/E" target="_blank" rel="noopener noreferrer">Гуманоид</a></h3>

<div class="header"><div class="title">E. Гуманоид</div><div class="time-limit"><div class="property-title">ограничение по времени на тест</div>2 секунды</div><div class="memory-limit"><div class="property-title">ограничение по памяти на тест</div>256 мегабайт</div><div class="input-file input-standard"><div class="property-title">ввод</div>стандартный ввод</div><div class="output-file output-standard"><div class="property-title">вывод</div>стандартный вывод</div></div><div><p>На некоторой космической станции работают $$$n$$$ космонавтов. Космонавт с номером $$$i$$$ ($$$1 \le i \le n$$$) имеет <span class="tex-font-style-it">стойкость</span> $$$a_i$$$.</p><p>На эту космическую станцию пробрался злобный гуманоид. <span class="tex-font-style-it">Сила</span> этого гуманоида равна $$$h$$$. Также гуманоид взял с собой <span class="tex-font-style-bf">две</span> <span class="tex-font-style-it">зелёных</span> сыворотки и <span class="tex-font-style-bf">одну</span> <span class="tex-font-style-it">синюю</span> сыворотку.</p><p>За одну секунду гуманоид может сделать любое из трёх действий:</p><ol> <li> поглотить космонавта со <span class="tex-font-style-it">стойкостью</span> <span class="tex-font-style-bf">строго меньше</span> <span class="tex-font-style-it">силы</span> гуманоида; </li><li> употребить <span class="tex-font-style-it">зелёную</span> сыворотку, если такая ещё осталась; </li><li> употребить <span class="tex-font-style-it">синюю</span> сыворотку, если такая ещё осталась. </li></ol><p>При поглощении космонавта со <span class="tex-font-style-it">стойкостью</span> $$$a_i$$$, этот космонавт исчезает, а <span class="tex-font-style-it">сила</span> гуманоида увеличивается на $$$\lfloor \frac{a_i}{2} \rfloor$$$, то есть целую часть от $$$\frac{a_i}{2}$$$. Например, если гуманоид поглощает космонавта со <span class="tex-font-style-it">стойкостью</span> $$$4$$$, его <span class="tex-font-style-it">сила</span> увеличивается на $$$2$$$, а если гуманоид поглощает космонавта со <span class="tex-font-style-it">стойкостью</span> $$$7$$$, его <span class="tex-font-style-it">сила</span> увеличивается на $$$3$$$.</p><p>При употреблении <span class="tex-font-style-it">зелёной</span> сыворотки, эта сыворотка исчезает, а <span class="tex-font-style-it">сила</span> гуманоида увеличивается в $$$2$$$ раза.</p><p>При употреблении <span class="tex-font-style-it">синей</span> сыворотки, эта сыворотка исчезает, а <span class="tex-font-style-it">сила</span> гуманоида увеличивается в $$$3$$$ раза.</p><p>Гуманоиду интересно, какое максимальное количество космонавтов он сможет поглотить, если будет действовать оптимально.</p></div><div class="input-specification"><div class="section-title">Входные данные</div><p>В первой строке входных данных дано целое число $$$t$$$ ($$$1 \le t \le 10^4$$$) — количество наборов входных данных.</p><p>В первой строке каждого набора входных данных даны целые числа $$$n$$$ ($$$1 \le n \le 2 \cdot 10^5$$$) — количество космонавтов и $$$h$$$ ($$$1 \le h \le 10^6$$$) — изначальная <span class="tex-font-style-it">сила</span> гуманоида.</p><p>Во второй строке каждого набора входных данных даны $$$n$$$ целых чисел $$$a_i$$$ ($$$1 \le a_i \le 10^8$$$) — <span class="tex-font-style-it">стойкости</span> космонавтов.</p><p>Гарантируется, что сумма $$$n$$$ по всем наборам входных данных не превосходит $$$2 \cdot 10^5$$$.</p></div><div class="output-specification"><div class="section-title">Выходные данные</div><p>Для каждого набора входных данных в отдельной строке выведите максимальное количество космонавтов, которое сможет поглотить гуманоид.</p></div><div class="sample-tests"><div class="section-title">Пример</div><div class="sample-test"><div class="input"><div
