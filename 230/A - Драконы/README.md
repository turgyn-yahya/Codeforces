Драконы</div><div class="time-limit"><div class="property-title">ограничение по времени на тест</div>2 секунды</div><div class="memory-limit"><div class="property-title">ограничение по памяти на тест</div>256 мегабайт</div><div class="input-file input-standard" style="font-weight: bold"><div class="property-title">ввод</div>stdin</div><div class="output-file output-standard" style="font-weight: bold"><div class="property-title">вывод</div>stdout</div></div><div><p>Кирито застрял на очередном уровне MMORPG, в которую он играет. Чтобы пройти игру дальше, ему нужно победить всех <span class="tex-span"><i>n</i></span> драконов, которые живут на этом уровне. Как Кирито, так и драконы обладают <span class="tex-font-style-underline">силой</span>, которая выражается целым числом. В схватке между двумя противниками исход схватки определяется их силой. Изначально сила Кирито равна <span class="tex-span"><i>s</i></span>.</p><p>Если Кирито вступает в схватку с <span class="tex-span"><i>i</i></span>-ым (<span class="tex-span">1 ≤ <i>i</i> ≤ <i>n</i></span>) драконом и его сила не больше, чем сила этого дракона <span class="tex-span"><i>x</i><sub class="lower-index"><i>i</i></sub></span>, то Кирито проигрывает схватку и умирает. Если же сила Кирито больше, чем сила дракона, то он побеждает дракона и получает бонус — его сила увеличивается на <span class="tex-span"><i>y</i><sub class="lower-index"><i>i</i></sub></span>.</p><p>Кирито может сражаться с драконами в произвольном порядке. Определите, сможет ли он пройти на следующий уровень игры, то есть победить всех драконов, не умирая ни разу.</p></div><div class="input-specification"><div class="section-title">Входные данные</div><p>Первая строка содержит два целых числа <span class="tex-span"><i>s</i></span> и <span class="tex-span"><i>n</i></span> (<span class="tex-span">1 ≤ <i>s</i> ≤ 10<sup class="upper-index">4</sup></span>, <span class="tex-span">1 ≤ <i>n</i> ≤ 10<sup class="upper-index">3</sup></span>), разделенные пробелом. Далее следуют <span class="tex-span"><i>n</i></span> строк: <span class="tex-span"><i>i</i></span>-ая строка содержит целые числа <span class="tex-span"><i>x</i><sub class="lower-index"><i>i</i></sub></span> и <span class="tex-span"><i>y</i><sub class="lower-index"><i>i</i></sub></span> (<span class="tex-span">1 ≤ <i>x</i><sub class="lower-index"><i>i</i></sub> ≤ 10<sup class="upper-index">4</sup></span>, <span class="tex-span">0 ≤ <i>y</i><sub class="lower-index"><i>i</i></sub> ≤ 10<sup class="upper-index">4</sup></span>), разделенные пробелом — силу <span class="tex-span"><i>i</i></span>-го дракона и бонус за победу над ним.</p></div><div class="output-specification"><div class="section-title">Выходные данные</div><p>В
