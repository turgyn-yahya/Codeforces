Контрастность</div><div class="time-limit"><div class="property-title">ограничение по времени на тест</div>2 секунды</div><div class="memory-limit"><div class="property-title">ограничение по памяти на тест</div>256 мегабайт</div><div class="input-file input-standard"><div class="property-title">ввод</div>стандартный ввод</div><div class="output-file output-standard"><div class="property-title">вывод</div>стандартный вывод</div></div><div><p>Для массива целых чисел $$$[a_1, a_2, \dots, a_n]$$$ значение $$$|a_1-a_2|+|a_2-a_3|+\cdots+|a_{n-1}-a_n|$$$ назовем <span class="tex-font-style-it">контрастностью</span> массива. Обратите внимание, что контрастность массива размера $$$1$$$ равен $$$0$$$.</p><p>Дан массив целых чисел $$$a$$$. Ваша задача — построить массив $$$b$$$ таким образом, чтобы выполнялись следующие условия:</p><ul> <li> $$$b$$$ не пустой, то есть содержит хотя бы один элемент; </li><li> $$$b$$$ является подпоследовательностью $$$a$$$, то есть $$$b$$$ может быть получен удалением некоторых элементов из $$$a$$$ (возможно, ни одного); </li><li> контрастность $$$b$$$ равна контрастности $$$a$$$. </li></ul><p>Каково минимально возможное количество элементов в массиве $$$b$$$?</p></div><div class="input-specification"><div class="section-title">Входные данные</div><p>Первая строка содержит одно размер массива $$$a$$$.</p><p>Вторая строка содержит $$$n$$$ целых чисел $$$a_1, a_2, \cdot, a_n$$$ ($$$0 \le a_i \le 10^9$$$) — элементы массива.</p><p>Сумма $$$n$$$ по всем наборам входных данных не
