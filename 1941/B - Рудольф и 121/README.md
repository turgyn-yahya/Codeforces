Рудольф и 121</div><div class="time-limit"><div class="property-title">ограничение по времени на тест</div>2 секунды</div><div class="memory-limit"><div class="property-title">ограничение по памяти на тест</div>256 мегабайт</div><div class="input-file input-standard"><div class="property-title">ввод</div>стандартный ввод</div><div class="output-file output-standard"><div class="property-title">вывод</div>стандартный вывод</div></div><div><p>У Рудольфа есть массив $$$a$$$ из $$$n$$$ целых чисел, элементы которого пронумерованы от $$$1$$$ до $$$n$$$. </p><p>За одну операцию он может выбрать индекс $$$i$$$ ($$$2 \le i \le n - 1$$$) и присвоить:</p><ul> <li> $$$a_{i - 1} = a_{i - 1} - 1$$$; </li><li> $$$a_i = a_i - 2$$$; </li><li> $$$a_{i + 1} = a_{i + 1} - 1$$$. </li></ul><p>Рудольф может применить эту операцию любое число раз.
