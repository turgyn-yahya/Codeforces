Например, числа $$$12321$$$, $$$6776$$$, $$$5$$$, $$$0$$$ являются палиндромами, а числа $$$123$$$ и $$$69$$$ — нет.</p></div></div><div class="input-specification"><div class="section-title">Входные данные</div><p>Каждый тест состоит из нескольких наборов входных данных.
