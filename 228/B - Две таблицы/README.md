Две таблицы</div><div class="time-limit"><div class="property-title">ограничение по времени на тест</div>2 секунды</div><div class="memory-limit"><div class="property-title">ограничение по памяти на тест</div>256 мегабайт</div><div class="input-file input-standard" style="font-weight: bold"><div class="property-title">ввод</div>stdin</div><div class="output-file output-standard" style="font-weight: bold"><div class="property-title">вывод</div>stdout</div></div><div><p>Вам заданы две прямоугольные таблицы размерами <span class="tex-span"><i>n</i><sub class="lower-index"><i>a</i></sub> × <i>m</i><sub class="lower-index"><i>a</i></sub></span> и <span class="tex-span"><i>n</i><sub class="lower-index"><i>b</i></sub> × <i>m</i><sub class="lower-index"><i>b</i></sub></span> клеток, состоящие из нулей и единиц. Будем считать, что строки и столбцы обеих таблиц нумеруются, начиная с 1. Тогда элемент первой таблицы, стоящий на пересечении <span class="tex-span"><i>i</i></span>-ой строки и <span class="tex-span"><i>j</i></span>-ого столбца, обозначим за <span class="tex-span"><i>a</i><sub class="lower-index"><i>i</i>, <i>j</i></sub></span>; элемент второй таблицы, стоящий на пересечении <span class="tex-span"><i>i</i></span>-ой строки и <span class="tex-span"><i>j</i></span>-ого столбца, обозначим за <span class="tex-span"><i>b</i><sub class="lower-index"><i>i</i>, <i>j</i></sub></span>. </p><p>Пару целых чисел <span class="tex-span">(<i>x</i>, <i>y</i>)</span> назовем <span class="tex-font-style-it">сдвигом</span> второй таблицы, относительно первой. <span class="tex-font-style-it">Коэффициентом совпадения</span> сдвига <span class="tex-span">(<i>x</i>, <i>y</i>)</span> назовем величину:</p><center class="tex-equation"><img align="middle" class="tex-formula" src="https://espresso.codeforces.com/5c01e65c9334a9379fe6e6233743a129489fdb76.png" style="max-width: 100.0%;max-height: 100.0%;"></center><p>где переменные <span class="tex-span"><i>i</i>, <i>j</i></span> принимают только такие значения, при которых выражение <span class="tex-span"><i>a</i><sub class="lower-index"><i>i</i>, <i>j</i></sub>·<i>b</i><sub class="lower-index"><i>i</i> + <i>x</i>, <i>j</i> + <i>y</i></sub></span> имеет смысл. Более формально, должны выполняться неравенства <span class="tex-span">1 ≤ <i>i</i> ≤ <i>n</i><sub class="lower-index"><i>a</i></sub>, 1 ≤ <i>j</i> ≤ <i>m</i><sub class="lower-index"><i>a</i></sub>, 1 ≤ <i>i</i> + <i>x</i> ≤ <i>n</i><sub class="lower-index"><i>b</i></sub>, 1 ≤ <i>j</i> + <i>y</i> ≤ <i>m</i><sub class="lower-index"><i>b</i></sub></span>. Если не существует значений переменных <span class="tex-span"><i>i</i>, <i>j</i></span>, удовлетворяющих заданным неравенствам, значение суммы считается равным 0. </p><p>Ваша задача — среди всех возможных сдвигов найти сдвиг с максимальным коэффициентом совпадения.</p></div><div class="input-specification"><div class="section-title">Входные данные</div><p>В первой строке через пробел записаны два целых числа <span class="tex-span"><i>n</i><sub class="lower-index"><i>a</i></sub>, <i>m</i><sub class="lower-index"><i>a</i></sub></span> <span class="tex-span">(1 ≤ <i>n</i><sub class="lower-index"><i>a</i></sub>, <i>m</i><sub class="lower-index"><i>a</i></sub> ≤ 50)</span> — количество строк и столбцов в первой таблице. Далее в <span class="tex-span"><i>n</i><sub class="lower-index"><i>a</i></sub></span> строках записано по <span class="tex-span"><i>m</i><sub class="lower-index"><i>a</i></sub></span> символов — элементы первой таблицы. Каждый символ является либо «<span class="tex-font-style-tt">0</span>», либо «<span class="tex-font-style-tt">1</span>».</p><p>В следующей строке через пробел записаны два целых числа <span class="tex-span"><i>n</i><sub class="lower-index"><i>b</i></sub>, <i>m</i><sub class="lower-index"><i>b</i></sub></span> <span class="tex-span">(1 ≤ <i>n</i><sub class="lower-index"><i>b</i></sub>, <i>m</i><sub class="lower-index"><i>b</i></sub> ≤ 50)</span> — количество строк и столбцов во второй таблице.
