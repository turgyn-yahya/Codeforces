<div class="header"><div class="title">D. Разнообразная гирлянда</div><div class="time-limit"><div class="property-title">ограничение по времени на тест</div>1 секунда</div><div class="memory-limit"><div class="property-title">ограничение по памяти на тест</div>256 мегабайт</div><div class="input-file input-standard"><div class="property-title">ввод</div>стандартный ввод</div><div class="output-file output-standard"><div class="property-title">вывод</div>стандартный вывод</div></div><div><p>У вас есть гирлянда, состоящая из $$$n$$$ ламп. Каждая лампа — красная, зеленая или синяя. Цвет $$$i$$$-й лампы равен $$$s_i$$$ ('<span class="tex-font-style-tt">R</span>', '<span class="tex-font-style-tt">G</span>' и '<span class="tex-font-style-tt">B</span>' — цвета ламп в гирлянде).</p><p>Вы хотите перекрасить некоторые лампы в этой гирлянде (перекрашивание лампы означает изменение ее изначального цвета на другой) таким образом, чтобы получившаяся гирлянда стала <span class="tex-font-style-bf">разнообразной</span>.</p><p>Гирлянда называется <span class="tex-font-style-bf">разнообразной</span>, если любые ее две соседние (последовательные) лампы (то есть такие лампы, что расстояние между их позициями равно $$$1$$$) имеют различные цвета.</p><p>Другими словами, если получилась гирлянда $$$t$$$, то для всех $$$i$$$ от $$$1$$$ до $$$n-1$$$ должно выполняться условие $$$t_i \ne t_{i + 1}$$$.</p><p>Среди всех способов перекрасить изначальную гирлянду в <span class="tex-font-style-bf">разнообразную</span> вы должны выбрать тот, в котором количество перекрашенных ламп <span class="tex-font-style-bf">минимально</span>. Если существует несколько оптимальных решений, выведите <span class="tex-font-style-bf">любое</span> из них.</p></div><div class="input-specification"><div class="section-title">Входные данные</div><p>Первая строка входных данных содержит одно целое число $$$n$$$ ($$$1 \le n \le 2 \cdot 10^5$$$) — количество ламп.</p><p>Вторая строка входных данных содержит строку $$$s$$$, состоящую из $$$n$$$ символов '<span class="tex-font-style-tt">R</span>', '<span class="tex-font-style-tt">G</span>' и '<span class="tex-font-style-tt">B</span>' — цвета ламп в гирлянде.</p></div><div class="output-specification"><div class="section-title">Выходные данные</div><p>В первой строке выходных данных выведите одно целое число $$$r$$$ — <span class="tex-font-style-bf">минимальное</span> количество перекрашиваний, необходимых для того, чтобы получить <span class="tex-font-style-bf">разнообразную</span> гирлянду из заданной.</p><p>Во второй строке выходных данных выведите одну строку $$$t$$$ длины $$$n$$$ — <span class="tex-font-style-bf">разнообразную</span> гирлянду, полученную из изначальной за <span class="tex-font-style-bf">минимальное</span> количество перекрашиваний.
