Администрация сайта хочет запустить свой проект как можно быстрее, поэтому они попросили Вас о помощи. Вам предлагается реализовать прототип системы регистрации сайта. </p><p>Система должна работать по следующему принципу. Каждый раз, когда новый пользователь хочет зарегистрироваться, он посылает системе запрос <span class="tex-font-style-tt">name</span> со своим именем. Если данное имя не содержится в базе данных системы, то оно заносится туда и пользователю возвращается ответ <span class="tex-font-style-tt">OK</span>, подтверждающий успешную регистрацию. Если же на сайте уже присутствует пользователь с именем <span class="tex-font-style-tt">name</span>, то система формирует новое имя и выдает его пользователю в качестве подсказки, <span class="tex-font-style-it">при этом подсказка также добавляется в базу данных</span>. Новое имя формируется по следующему правилу. К <span class="tex-font-style-tt">name</span> последовательно приписываются числа, начиная с единицы (<span class="tex-font-style-tt">name</span>1, <span class="tex-font-style-tt">name</span>2, ...), и среди них находят такое наименьшее <span class="tex-span"><i>i</i></span>, что <span class="tex-font-style-tt">name</span><span class="tex-span"><i>i</i></span> не содержится в базе данных сайта.</p></div><div class="input-specification"><div class="section-title">Входные данные</div><p>В первой строке входных данных задано число <span class="tex-span"><i>n</i></span> (<span class="tex-span">1 ≤ <i>n</i> ≤ 10<sup class="upper-index">5</sup></span>). Следующие <span class="tex-span"><i>n</i></span> строк содержат запросы к системе. Каждый запрос представляет собой непустую строку длиной не более 32 символов, состоящую только из строчных букв латинского алфавита.</p></div><div class="output-specification"><div class="section-title">Выходные данные</div><p>В выходных данных должно содержаться <span class="tex-span"><i>n</i></span> строк — ответы системы на запросы: <span class="tex-font-style-tt">ОК</span> в случае успешной регистрации, или подсказку с новым именем, если запрашиваемое уже занято.</p></div><div class="sample-tests"><div class="section-title">Примеры</div><div class="sample-test"><div class="input"><div class="title">Входные данные<div title="Скопировать" data-clipboard-target="#id002793097645792578" id="id006387719022498913" class="input-output-copier">Скопировать</div></div><pre id="id002793097645792578">4<br>abacaba<br>acaba<br>abacaba<br>acab<br></pre></div><div class="output"><div class="title">Выходные данные<div title="Скопировать" data-clipboard-target="#id006549373918166267" id="id002889653490818438" class="input-output-copier">Скопировать</div></div><pre id="id006549373918166267">OK<br>OK<br>abacaba1<br>OK<br></pre></div><div class="input"><div class="title">Входные данные<div title="Скопировать" data-clipboard-target="#id006304154382624937" id="id003413790464819819" class="input-output-copier">Скопировать</div></div><pre id="id006304154382624937">6<br>first<br>first<br>second<br>second<br>third<br>third<br></pre></div><div class="output"><div class="title">Выходные данные<div title="Скопировать" data-clipboard-target="#id009819786610878272" id="id006419839860847656" class="input-output-copier">Скопировать</div></div><pre id="id009819786610878272">OK<br>first1<br>OK<br>second1<br>OK<br>third1<br></pre></div></div></div>
