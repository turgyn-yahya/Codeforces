<h3><a href="https://codeforces.com/contest/2195/problem/A" target="_blank" rel="noopener noreferrer">Решето Эратосфена</a></h3>

<div class="header"><div class="title">A. Решето Эратосфена</div><div class="time-limit"><div class="property-title">ограничение по времени на тест</div>1 секунда</div><div class="memory-limit"><div class="property-title">ограничение по памяти на тест</div>256 мегабайт</div><div class="input-file input-standard"><div class="property-title">ввод</div>стандартный ввод</div><div class="output-file output-standard"><div class="property-title">вывод</div>стандартный вывод</div></div><div><p>Вам даны $$$n$$$ <span class="tex-font-style-bf">положительных</span> целых чисел $$$a_1,a_2,\ldots,a_n$$$.</p><p>Пожалуйста, определите, возможно ли выбрать любое количество элементов из $$$a$$$, так чтобы их произведение было равно $$$67$$$.</p><p>Обратите внимание, что вы не можете выбрать ноль элементов, так как произведение нуля элементов не определено в этой задаче.</p></div><div class="input-specification"><div class="section-title">Входные данные</div><p>Каждый тест состоит из нескольких наборов входных данных. В первой строке находится одно целое число $$$t$$$ ($$$1 \le t \le 10^4$$$) — количество наборов входных данных. Далее следует описание наборов входных данных. </p><p>Первая строка каждого набора содержит одно целое число $$$n$$$ ($$$1 \le n \le 5$$$).</p><p>Вторая строка каждого набора содержит $$$n$$$ положительных целых чисел $$$a_1,a_2,\ldots,a_n$$$ ($$$1 \le a_i \le 67$$$).</p></div><div class="output-specification"><div class="section-title">Выходные данные</div><p>Если возможно выбрать элементы так, чтобы их произведение было равно $$$67$$$, выведите «<span class="tex-font-style-tt">YES</span>» в одной строке. В противном случае выведите «<span class="tex-font-style-tt">NO</span>» в одной строке.</p><p>Вы можете выводить ответ в любом регистре. Например, строки «<span class="tex-font-style-tt">yEs</span>», «<span class="tex-font-style-tt">yes</span>» и «<span class="tex-font-style-tt">Yes</span>» также будут распознаны как положительные ответы.</p></div><div class="sample-tests"><div class="section-title">Пример</div><div class="sample-test"><div class="input"><div class="title">Входные данные<div title="Скопировать" data-clipboard-target="#id005731415215093297" id="id006356079005654943" class="input-output-copier">Скопировать</div></div><pre id="id005731415215093297"><div class="test-example-line test-example-line-even test-example-line-0">2</div><div class="test-example-line test-example-line-odd test-example-line-1">5</div><div class="test-example-line test-example-line-odd test-example-line-1">1 7 6 7 67</div><div class="test-example-line test-example-line-even test-example-line-2">5</div><div class="test-example-line test-example-line-even test-example-line-2">1 3 5 7 8</div></pre></div><div class="output"><div class="title">Выходные данные<div title="Скопировать" data-clipboard-target="#id0018367065816893446" id="id004215675743577576" class="input-output-copier">Скопировать</div></div><pre id="id0018367065816893446"><div class="test-example-line test-example-line-odd test-example-line-1">YES</div><div class="test-example-line test-example-line-even test-example-line-2">NO</div></pre></div></div></div><div class="note"><div class="section-title">Примечание</div><p>В первом примере вы можете выбрать $$$a_1$$$ и $$$a_5$$$, чтобы получить $$$a_1\cdot a_5 = 1 \cdot 67 = 67$$$.</p><p>Во втором примере невозможно выбрать любое количество элементов так, чтобы их произведение оказалось равно $$$67$$$.</p></div>
