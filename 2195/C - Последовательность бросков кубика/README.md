<div class="header"><div class="title">C. Последовательность бросков кубика</div><div class="time-limit"><div class="property-title">ограничение по времени на тест</div>2 секунды</div><div class="memory-limit"><div class="property-title">ограничение по памяти на тест</div>256 мегабайт</div><div class="input-file input-standard"><div class="property-title">ввод</div>стандартный ввод</div><div class="output-file output-standard"><div class="property-title">вывод</div>стандартный вывод</div></div><div><p>Рассмотрим следующий куб $$$D$$$, на котором числа $$$x$$$ и $$$7-x$$$ <span class="tex-font-style-bf">находятся на противоположных гранях</span>:</p><center> <img class="tex-graphics" src="https://espresso.codeforces.com/e047423e2d0117d489bd89afd6732f829aa2c224.png" style="zoom: 75.0%;max-width: 100.0%;max-height: 100.0%;">   <span class="tex-font-size-small">Изображение сгенерировано Nano Banana Pro.</span> </center><p>Последовательность $$$b$$$ целых чисел от $$$1$$$ до $$$6$$$ называется <span class="tex-font-style-it">последовательностью бросков кубика</span>, если она удовлетворяет следующему условию:</p><ul> <li> Все пары соседних элементов находятся на смежных$$$^{\text{∗}}$$$ гранях кубика. </li></ul><p>Например, $$$[1,4,2]$$$ является последовательностью бросков кубика, в то время как $$$[3,4,6,3]$$$ не является таковой, потому что $$$3$$$ и $$$4$$$ находятся не на смежных гранях кубика. Кроме того, $$$[2,2,4]$$$ не является последовательностью бросков кубика, потому что $$$2$$$ и $$$2$$$ находятся на одной (не смежной) грани кубика.</p><p>Дана последовательность $$$a$$$ из $$$n$$$ целых чисел от $$$1$$$ до $$$6$$$, вы можете выполнять следующую операцию любое количество раз (возможно, ноль).</p><ul> <li> Выберите индекс $$$1 \le i \le n$$$ и целое число $$$1 \le x \le 6$$$. Затем измените значение $$$a_i$$$ на $$$x$$$. </li></ul><p>Пожалуйста, определите <span class="tex-font-style-bf">минимальное количество операций</span>, необходимых для того, чтобы сделать $$$a$$$ последовательностью бросков кубика.</p><div class="statement-footnote"><p>$$$^{\text{∗}}$$$Две грани кубика $$$S$$$ и $$$T$$$ называются <span class="tex-font-style-it">смежными</span>, если они имеют <span class="tex-font-style-bf">ровно</span> одно общее ребро кубика. <span class="tex-font-style-bf">Обратите внимание, что</span> это условие также подразумевает $$$S \neq T$$$.</p></div></div><div class="input-specification"><div class="section-title">Входные данные</div><p>Каждый тест состоит из нескольких наборов входных данных. Далее следует описание наборов входных данных. </p><p>Первая строка каждого набора содержит одно целое число $$$n$$$ ($$$1 \le n \le 3 \cdot 10^5$$$).</p><p>Вторая строка каждого набора содержит $$$n$$$ целых чисел $$$a_1,a_2,\ldots,a_n$$$ ($$$1 \le a_i \le 6$$$).</p><p>Гарантируется, что сумма $$$n$$$ по всем наборам входных данных не превышает $$$3 \cdot 10^5$$$.</p></div><div
