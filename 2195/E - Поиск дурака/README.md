<h3><a href="https://codeforces.com/contest/2195/problem/E" target="_blank" rel="noopener noreferrer">Поиск дурака</a></h3>

<div class="header"><div class="title">E. Поиск дурака</div><div class="time-limit"><div class="property-title">ограничение по времени на тест</div>2 секунды</div><div class="memory-limit"><div class="property-title">ограничение по памяти на тест</div>512 мегабайт</div><div class="input-file input-standard"><div class="property-title">ввод</div>стандартный ввод</div><div class="output-file output-standard"><div class="property-title">вывод</div>стандартный вывод</div></div><div><p>Существует бинарное дерево из $$$n+1$$$ вершин (<span class="tex-font-style-bf">$$$n$$$ нечетное</span>), с вершинами, помеченными $$$0,1,\ldots,n$$$. <span class="tex-font-style-bf">На каждой вершине</span> может быть написана не более одной буквы, и изначально на всех вершинах ничего не написано. Корень дерева — это вершина $$$0$$$.</p><p>В дереве вершина $$$0$$$ является родителем вершины $$$1$$$, в то время как у всех остальных вершин либо $$$2$$$ ребёнка, либо $$$0$$$.</p><p>Боб заблудился в одной из вершин дерева и хочет выбраться из дерева, добравшись до вершины $$$0$$$. Это очень легко для большинства людей с обычным здравым смыслом. Однако, поскольку Боб — дурак, он придумал новый способ обхода дерева, введя «Поиск дурака».</p><p>Когда Боб находится на вершине $$$v$$$ ($$$1 \le v \le n$$$), его движение определяется следующим образом:</p><ul> <li> Если вершина $$$v$$$ является листом, Боб <span class="tex-font-style-bf">всегда</span> движется к родителю $$$v$$$; в противном случае он проверяет следующие условия. </li><li> Если на вершине $$$v$$$ ничего не написано, Боб пишет '<span class="tex-font-style-tt">L</span>' на вершине $$$v$$$ и движется к левому ребенку $$$v$$$; </li><li> Если на вершине $$$v$$$ написано '<span class="tex-font-style-tt">L</span>', Боб <span class="tex-font-style-bf">перезаписывает</span> её на '<span class="tex-font-style-tt">R</span>' и движется к правому ребенку $$$v$$$; </li><li> Если на вершине $$$v$$$ написано '<span class="tex-font-style-tt">R</span>', Боб <span class="tex-font-style-bf">стирает</span> её и движется к родителю $$$v$$$. </li></ul><p>Бобу требуется ровно $$$1$$$ секунда, чтобы перейти к соседней вершине, так что Боб потратит ровно $$$x$$$ секунд на выполнение $$$x$$$ перемещений.</p><p>Доказано, что независимо от того, с какой вершины начинает Боб, он может добраться до вершины $$$0$$$ за конечное (хотя и возможно необъяснимо большое) время. Мы не знаем, кто это доказал; конечно, это не мог быть Боб, но это определенно доказано.</p><p>Для каждой вершины $$$k=1,2,\ldots,n$$$ определите общее время, необходимое для достижения вершины $$$0$$$, если Боб начал с вершины $$$k$$$, в секундах. Поскольку значения могут быть огромными, вам нужно вычислить их по модулю $$$10^9+7$$$.</p></div><div class="input-specification"><div class="section-title">Входные данные</div><p>Каждый тест состоит из нескольких наборов входных данных. В первой строке находится одно целое число $$$t$$$ ($$$1 \le t \le 10^4$$$) — количество наборов входных данных. Далее следует описание наборов входных данных. </p><p>Первая строка каждого набора содержит одно целое число $$$n$$$ ($$$1 \le n \le 300\,001$$$, <span class="tex-font-style-bf">$$$n$$$ нечетное</span>).</p><p>Каждая из следующих $$$n$$$ строк содержит два целых числа $$$l_i$$$ и $$$r_i$$$, обозначающие детей вершины $$$i$$$ ($$$0 \le l_i,r_i \le n$$$).</p><p>Для каждой вершины, если $$$l_i=r_i=0$$$, это означает, что у вершины нет детей. В противном случае $$$l_i$$$ и $$$r_i$$$ — это левый и правый дети вершины $$$i$$$.</p><p>Гарантируется, что входные данные определяют корректное бинарное дерево, удовлетворяющее условиям, указанным в условии.</p><p>Гарантируется, что сумма $$$n$$$ по всем наборам входных данных не превышает $$$300\,001$$$.</p></div><div class="output-specification"><div class="section-title">Выходные данные</div><p>Для каждого набора входных данных выведите $$$n$$$ целых чисел $$$\tau_1,\tau_2,\ldots,\tau_n$$$, разделенных пробелами.</p><p>Здесь $$$\tau_k$$$ обозначает общее время, необходимое для достижения вершины $$$0$$$, если Боб начал с вершины $$$k$$$, по модулю $$$10^9+7$$$.</p></div><div class="sample-tests"><div class="section-title">Пример</div><div class="sample-test"><div
