Они ее решили, а после этого Ехаб задал Махмуду другую задачу.</p><p>Дано две строки <span class="tex-span"><i>a</i></span> и <span class="tex-span"><i>b</i></span>, найдите длину их наибольшей не общей подпоследовательности, то есть такой строки, которая является подпоследовательностью одной строки и не является подпоследовательностью другой.</p><p>Подпоследовательность некоторой строки это последовательность букв, которая встречается в том же порядке в строке, не обязательно подряд. Например, строки «<span class="tex-font-style-tt">ac</span>», «<span class="tex-font-style-tt">bc</span>», «<span class="tex-font-style-tt">abc</span>» и «<span class="tex-font-style-tt">a</span>» являются подпоследовательностями строки «<span class="tex-font-style-tt">abc</span>», а строки «<span class="tex-font-style-tt">abbc</span>» и «<span class="tex-font-style-tt">acb</span>» — нет. Пустая строка является подпоследовательностью любой строки, любая строка является подпоследовательностью ее самой.</p></div><div class="input-specification"><div class="section-title">Входные данные</div><p>Первая строка содержит строку <span class="tex-span"><i>a</i></span>, а вторая строка — строку <span class="tex-span"><i>b</i></span>. Обе строки не пусты и состоят из строчных букв латинского алфавита.
