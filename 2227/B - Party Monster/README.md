<h3><a href="https://codeforces.com/contest/2227/problem/B" target="_blank" rel="noopener noreferrer">Party Monster</a></h3>

<div class="header"><div class="title">B. Party Monster</div><div class="time-limit"><div class="property-title">ограничение по времени на тест</div>2 секунды</div><div class="memory-limit"><div class="property-title">ограничение по памяти на тест</div>256 мегабайт</div><div class="input-file input-standard"><div class="property-title">ввод</div>стандартный ввод</div><div class="output-file output-standard"><div class="property-title">вывод</div>стандартный вывод</div></div><div><p>Юсеф дал вам последовательность $$$s$$$ длины $$$n$$$, состоящую только из символов '$$$\texttt{(}$$$' и '$$$\texttt{)}$$$'. Вам разрешается выполнить следующую операцию <span class="tex-font-style-bf">не более одного раза</span>: </p><ul> <li> Выберите подстроку$$$^{\text{∗}}$$$ строки $$$s$$$ и удалите её. Затем вы можете вставить удалённые символы обратно в оставшуюся строку по одному. Каждый символ можно вставить в любое произвольное место, независимо от остальных. </li></ul><p>Юсеф хочет, чтобы вы определили, можно ли получить правильную скобочную последовательность$$$^{\text{†}}$$$ после выполнения операции не более одного раза.</p><div class="statement-footnote"><p>$$$^{\text{∗}}$$$ <span class="tex-font-style-it">Подстрока</span> — это непрерывный подотрезок строки. Например, <span class="tex-font-style-tt">"acab"</span> является подстрокой <span class="tex-font-style-tt">"abacaba"</span> (она начинается в позиции $$$3$$$ и заканчивается в позиции $$$6$$$), а <span class="tex-font-style-tt">"aa"</span> или <span class="tex-font-style-tt">"d"</span> не являются подстроками этой строки. То есть подстрока строки $$$s$$$ от позиции $$$l$$$ до позиции $$$r$$$ — это $$$s[l, r]= s_l s_{l+1} \dots s_r$$$.</p><p>$$$^{\text{†}}$$$ <span class="tex-font-style-it">Правильная скобочная последовательность</span> — это скобочная последовательность, которую можно преобразовать в корректное арифметическое выражение, вставив символы $$$1$$$ и $$$+$$$ между исходными символами последовательности. Например:</p><ul> <li> скобочные последовательности $$$\texttt{()()}$$$ и $$$\texttt{(())}$$$ являются правильными (получающиеся выражения: $$$\texttt{(1)+(1)}$$$ и $$$\texttt{((1+1)+1)}$$$); </li><li> скобочные последовательности $$$\texttt{)(}$$$, $$$\texttt{(}$$$ и $$$\texttt{)}$$$ — не являются. </li></ul></div></div><div class="input-specification"><div class="section-title">Входные данные</div><p>Первая строка содержит целое число $$$t$$$ ($$$1 \le t \le 10^4$$$) — количество наборов входных данных. Далее следует описание наборов входных данных.</p><p>Первая строка каждого набора входных данных содержит одно целое число $$$n$$$ ($$$1 \le n \le 2 \cdot 10^5$$$) — длину строки $$$s$$$.</p><p>Вторая строка каждого набора входных данных содержит строку $$$s$$$ длины $$$n$$$, состоящую только из символов '$$$\texttt{(}$$$' и '$$$\texttt{)}$$$'.</p><p>Гарантируется, что сумма $$$n$$$ по всем наборам входных данных не превосходит $$$2 \cdot 10^5$$$.</p></div><div class="output-specification"><div class="section-title">Выходные данные</div><p>Для каждого набора входных данных выведите «<span class="tex-font-style-tt">YES</span>», если последовательность можно сделать правильной, и «<span class="tex-font-style-tt">NO</span>» в противном случае.</p><p>Ответ можно выводить в любом регистре (верхнем или нижнем).
