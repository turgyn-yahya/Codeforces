Как-то раз Никита решил съездить с его другом Алексеем на чемпионат мира по летнему биатлону. Никита, как особо важная персона, получил жетон, позволяющий ставить на каждом участке не более чем на одного спортсмена. </p><p>Для начала друзья узнали правила: в гонке <span class="tex-span"><i>n</i></span> участков равной длины и <span class="tex-span"><i>m</i></span> участников. Участники пронумерованы от <span class="tex-span">1</span> до <span class="tex-span"><i>m</i></span>. Про каждого участника известно:</p><ul><li> <span class="tex-span"><i>l</i><sub class="lower-index"><i>i</i></sub></span> — номер участка, с которого биатлонист начинает бежать,</li><li> <span class="tex-span"><i>r</i><sub class="lower-index"><i>i</i></sub></span> — номер участка, на котором биатлонист заканчивает бежать,</li><li> <span class="tex-span"><i>t</i><sub class="lower-index"><i>i</i></sub></span> — время, которое требуется биатлонисту чтобы преодолеть один участок пути,</li><li> <span class="tex-span"><i>c</i><sub class="lower-index"><i>i</i></sub></span> — прибыль в рублях, которую получит поставивший на него человек, в случае победы <span class="tex-span"><i>i</i></span>-ого спортсмена на одном из участков.</li></ul> <p><span class="tex-span"><i>i</i></span>-ый биатлонист проезжает участки с <span class="tex-span"><i>l</i><sub class="lower-index"><i>i</i></sub></span> по <span class="tex-span"><i>r</i><sub class="lower-index"><i>i</i></sub></span> включительно. Весь путь участник пробегает за <span class="tex-span">(<i>r</i><sub class="lower-index"><i>i</i></sub> - <i>l</i><sub class="lower-index"><i>i</i></sub> + 1)·<i>t</i><sub class="lower-index"><i>i</i></sub></span> единиц времени. Одну секцию участник пробегает ровно за <span class="tex-span"><i>t</i><sub class="lower-index"><i>i</i></sub></span> единиц времени. В случае победы спортсмена на <span class="tex-span"><i>k</i></span> участках поставивший на него получит <span class="tex-span"><i>k</i>·<i>c</i><sub class="lower-index"><i>i</i></sub></span> рублей. </p><p>На каждом участке победитель определяется <span class="tex-font-style-bf">независимо</span> следующим образом: если есть хотя бы один биатлонист, бегущий данный участок, то из всех них победителем является тот, кто пробежал этот участок за минимальное время (преодолел участок за меньшее время, чем другие). В случае равенства времени побеждает спортсмен с меньшим порядковым номером. Если же участников этапа нет, то победитель на этом этапе неопределен. Стоит добавить, что в летнем биатлоне все участники движутся с постоянной скоростью.</p><p>Также стоит добавить, что Никита может ставить на каждом участке на любого участника, бегущего данный участок.</p><p>Помогите друзьям определить максимальную возможную прибыль.</p></div><div class="input-specification"><div class="section-title">Входные данные</div><p>В первой строке находится два целых числа <span class="tex-span"><i>n</i></span> и <span class="tex-span"><i>m</i></span> (<span class="tex-span">1 ≤ <i>n</i>, <i>m</i> ≤ 100</span>).
