<div class="header"><div class="title">B. Размер жюри</div><div class="time-limit"><div class="property-title">ограничение по времени на тест</div>1 секунда</div><div class="memory-limit"><div class="property-title">ограничение по памяти на тест</div>256 мегабайт</div><div class="input-file" style="font-weight: bold"><div class="property-title">ввод</div>input.txt</div><div class="output-file" style="font-weight: bold"><div class="property-title">вывод</div>output.txt</div></div><div><p>В 2013-м году авторский коллектив Берляндского государственного университета должен подготовить задачи к <span class="tex-span"><i>n</i></span> олимпиадам. Будем считать, что олимпиады пронумерованы последовательными целыми числами от 1 до <span class="tex-span"><i>n</i></span>. Про каждую олимпиаду известно, сколько членов жюри должно участвовать в ее подготовке, а также время, требуемое на подготовку задач для нее. А именно, олимпиаду с номером <span class="tex-span"><i>i</i></span> должны готовить <span class="tex-span"><i>p</i><sub class="lower-index"><i>i</i></sub></span> человек в течение <span class="tex-span"><i>t</i><sub class="lower-index"><i>i</i></sub></span> дней, причем подготовка олимпиады должна вестись непрерывный промежуток времени и закончиться ровно за день до олимпиады. Непосредственно в день олимпиады члены жюри, которые ее готовили, уже над ней не работают. </p><p>К примеру, если олимпиада состоится 9 декабря, и на ее подготовку требуется 7 человек и 6 дней, то все эти 7 членов жюри будут работать над задачами этой олимпиады с 3-го декабря по 8-е декабря (9-го декабря эти члены жюри уже не будут работать над задачами этой олимпиады, то есть некоторые из них могут начать готовить задачи какой-то другой олимпиады). А если олимпиада проводится 3 ноября и требует 5 дней подготовки, то члены жюри будут работать с 29-го октября по 2-е ноября. </p><p>Чтобы не перегружать членов жюри, было введено такое правило: один член жюри не может в один и тот же день работать над задачами для разных олимпиад. Напишите программу, которая определяет, какое наименьшее количество человек должно входить в состав жюри, чтобы все олимпиады могли быть подготовлены в срок.</p></div><div class="input-specification"><div class="section-title">Входные данные</div><p>В первой строке записано целое число <span class="tex-span"><i>n</i></span> — количество олимпиад в 2013-м году (<span class="tex-span">1 ≤ <i>n</i> ≤ 100</span>). Каждая из следующих <span class="tex-span"><i>n</i></span> строк содержит по четыре целых числа <span class="tex-span"><i>m</i><sub class="lower-index"><i>i</i></sub></span>, <span class="tex-span"><i>d</i><sub class="lower-index"><i>i</i></sub></span>, <span class="tex-span"><i>p</i><sub class="lower-index"><i>i</i></sub></span> и <span class="tex-span"><i>t</i><sub class="lower-index"><i>i</i></sub></span> — месяц и день олимпиады (заданы без лидирующих нулей), требуемое количество членов жюри и время, требуемое на подготовку <span class="tex-span"><i>i</i></span>-й олимпиады (<span class="tex-span">1 ≤ <i>m</i><sub class="lower-index"><i>i</i></sub> ≤ 12</span>, <span class="tex-span"><i>d</i><sub class="lower-index"><i>i</i></sub> ≥ 1</span>, <span class="tex-span">1 ≤ <i>p</i><sub class="lower-index"><i>i</i></sub>, <i>t</i><sub class="lower-index"><i>i</i></sub> ≤ 100</span>), <span class="tex-span"><i>d</i><sub class="lower-index"><i>i</i></sub></span> не превосходит количества дней в месяце <span class="tex-span"><i>m</i><sub class="lower-index"><i>i</i></sub></span>. Олимпиады заданы в произвольном порядке. В один день может проводиться несколько олимпиад.</p><p>Для решения задачи используйте современный (Григорианский) календарь. Обратите внимание, все даты заданы в 2013 году. Этот год не является високосным, следовательно, в феврале 28 дней. <span class="tex-font-style-bf">Обратите внимание, подготовка некоторой олимпиады может начаться в 2012 году.</span></p></div><div
