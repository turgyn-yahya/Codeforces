<h3><a href="https://codeforces.com/contest/1742/problem/D" target="_blank" rel="noopener noreferrer">Взаимно простые</a></h3>

<div class="header"><div class="title">D. Взаимно простые</div><div class="time-limit"><div class="property-title">ограничение по времени на тест</div>3 секунды</div><div class="memory-limit"><div class="property-title">ограничение по памяти на тест</div>256 мегабайт</div><div class="input-file input-standard"><div class="property-title">ввод</div>стандартный ввод</div><div class="output-file output-standard"><div class="property-title">вывод</div>стандартный вывод</div></div><div><p>Дан массив из $$$n$$$ целых положительных чисел $$$a_1, a_2, \dots, a_n$$$ ($$$1 \le a_i \le 1000$$$). Выведите максимальное значение $$$i + j$$$ такое, что $$$a_i$$$ и $$$a_j$$$ взаимно простые$$$^{\dagger}$$$, или $$$-1$$$, если таких $$$i$$$ и $$$j$$$ не существует.</p><p>Например, рассмотрим массив $$$[1, 3, 5, 2, 4, 7, 7]$$$. Максимальное значение $$$i + j$$$, которое можно получить, равно $$$5 + 7$$$, так как $$$a_5 = 4$$$ и $$$a_7 = 7$$$ являются взаимно простые.</p><p>$$$^{\dagger}$$$ Два целых числа $$$p$$$ и $$$q$$$ являются <a href="https://ru.wikipedia.org/wiki/Взаимно_простые_числа">взаимно простыми</a>, если единственное положительное целое число, которое является делителем их обоих, равно $$$1$$$ (их <a href="https://ru.wikipedia.org/wiki/Наибольший_общий_делитель">наибольший общий делитель</a> равен $$$1$$$).</p></div><div class="input-specification"><div class="section-title">Входные данные</div><p>Входные данные состоят из нескольких наборов. Первая строка содержит целое число $$$t$$$ ($$$1 \leq t \leq 10$$$) — количество наборов. Далее следует их описание.</p><p>Первая строка каждого набора содержит целое число $$$n$$$ ($$$2 \leq n \leq 2\cdot10^5$$$) — количество элементов в массиве.</p><p>Следующая строка содержит $$$n$$$ разделенных пробелами положительных чисел $$$a_1$$$, $$$a_2$$$,..., $$$a_n$$$ ($$$1 \leq a_i \leq 1000$$$) — элементы массива.</p><p>Гарантируется, что сумма $$$n$$$ по всем тестовым случаям не превышает $$$2\cdot10^5$$$.</p></div><div class="output-specification"><div class="section-title">Выходные данные</div><p>Для каждого набора выведите одно целое число  — максимальное значение $$$i + j$$$, такое, что $$$i$$$ и $$$j$$$ удовлетворяют условию, что $$$a_i$$$ и $$$a_j$$$ взаимно просты, или выведите $$$-1$$$, если не существует таких $$$i$$$ и $$$j$$$.</p></div><div
