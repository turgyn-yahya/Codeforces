<h3><a href="https://codeforces.com/contest/1914/problem/C" target="_blank" rel="noopener noreferrer">Квесты</a></h3>

<div class="header"><div class="title">C. Квесты</div><div class="time-limit"><div class="property-title">ограничение по времени на тест</div>2.5 секунд</div><div class="memory-limit"><div class="property-title">ограничение по памяти на тест</div>256 мегабайт</div><div class="input-file input-standard"><div class="property-title">ввод</div>стандартный ввод</div><div class="output-file output-standard"><div class="property-title">вывод</div>стандартный вывод</div></div><div><p>Монокарп играет в компьютерную игру. Чтобы повысить уровень персонажа, он может выполнять квесты. В игре есть $$$n$$$ квестов, пронумерованных от $$$1$$$ до $$$n$$$.</p><p>Монокарп может выполнять квесты согласно следующим правилам: </p><ul> <li> $$$1$$$-й квест всегда доступен для выполнения; </li><li> $$$i$$$-й квест доступен для выполнения, если каждый квест $$$j  \lt  i$$$ был выполнен хотя бы раз. </li></ul><p>Обратите внимание, что Монокарп может выполнять один и тот же квест несколько раз.</p><p>За каждое выполнение персонаж получает некоторое количество опыта: </p><ul> <li> за первое выполнение $$$i$$$-го квеста он получает $$$a_i$$$ очков опыта; </li><li> за каждое последующее выполнение $$$i$$$-го квеста он получает $$$b_i$$$ очков опыта. </li></ul><p>Монокарп очень занятой человек, поэтому у него есть свободное время, чтобы выполнить не более $$$k$$$ квестов. Ваша задача — посчитайте максимально возможный суммарный опыт, который Монокарп может получить, если он может выполнить не более $$$k$$$ квестов.</p></div><div class="input-specification"><div class="section-title">Входные данные</div><p>Первая строка содержит одно целое число $$$t$$$ ($$$1 \le t \le 10^4$$$) — количество наборов входных данных.</p><p>Первая строка каждого набора содержит два целых числа $$$n$$$ и $$$k$$$ ($$$1 \le n \le 2 \cdot 10^5$$$; $$$1 \le k \le 2 \cdot 10^5$$$) — количество квестов и максимальное количество квестов, которые Монокарп может выполнить, соответственно.</p><p>Вторая строка содержит $$$n$$$ целых чисел $$$a_1, a_2, \dots, a_n$$$ ($$$1 \le a_i \le 10^3$$$).</p><p>Третья строка содержит $$$n$$$ целых чисел $$$b_1, b_2, \dots, b_n$$$ ($$$1 \le b_i \le 10^3$$$).</p><p>Дополнительное ограничение на входные данные: сумма $$$n$$$ по всем наборам входных данных не превосходит $$$2 \cdot 10^5$$$.</p></div><div class="output-specification"><div class="section-title">Выходные данные</div><p>Для каждого набора входных данных выведите одно целое число — максимально возможный суммарный опыт, который Монокарп
