За одну операцию вы можете сделать следующее:</p><ul><li> Выбрать индекс $$$1 \leq i \leq n$$$,</li><li> Сделать $$$a_i = a_i + 1$$$.</li></ul><p>Найдите наименьшее количество операций, которые нужно сделать, чтобы произведение всех чисел массива $$$a_1 \cdot a_2 \cdot \ldots \cdot a_n$$$ делилось на $$$k$$$.</p></div><div class="input-specification"><div class="section-title">Входные данные</div><p>Каждый тест состоит из нескольких наборов входных данных. число $$$k$$$.</p><p>Вторая строка каждого набора входных данных содержит $$$n$$$ целых чисел $$$a_1, a_2, \ldots, a_n$$$ ($$$1 \leq a_i \leq 10$$$).</p><p>Гарантируется, что сумма $$$n$$$ по всем
