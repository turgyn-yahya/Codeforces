Выражение</div><div class="time-limit"><div class="property-title">ограничение по времени на тест</div>1 секунда</div><div class="memory-limit"><div class="property-title">ограничение по памяти на тест</div>256 мегабайт</div><div class="input-file input-standard" style="font-weight: bold"><div class="property-title">ввод</div>stdin</div><div class="output-file output-standard" style="font-weight: bold"><div class="property-title">вывод</div>stdout</div></div><div><p>Петя учится в школе и очень любит математику. Уже несколько занятий они с классом проходят арифметические выражения. На последнем уроке учительница написала на доске три положительных целых числа <span class="tex-span"><i>a</i></span>, <span class="tex-span"><i>b</i></span>, <span class="tex-span"><i>c</i></span>. Задание заключалось в том, чтобы расставить между этими числами знаки операций '<span class="tex-font-style-tt">+</span>' и '<span class="tex-font-style-tt">*</span>', а также, возможно, скобки. Значение получившегося выражения должно быть как можно больше. Рассмотрим пример: пусть учительница выписала на доску числа 1, 2 и 3. Вот некоторые варианты расстановки знаков и скобок:</p><ul> <li> 1+2*3=7 </li><li> 1*(2+3)=5 </li><li> 1*2*3=6 </li><li> (1+2)*3=9 </li></ul><p>Обратите внимание на то, что знаки операций можно вставлять только между <span class="tex-span"><i>a</i></span> и <span class="tex-span"><i>b</i></span>, а также между <span class="tex-span"><i>b</i></span> и <span class="tex-span"><i>c</i></span>, то есть нельзя менять числа местами. Так, в приведенном примере нельзя получить выражение (1+3)*2.</p><p>Легко убедиться, что максимальное значение, которое можно получить, — это 9.</p><p>Ваша задача — по заданным <span class="tex-span"><i>a</i></span>, <span class="tex-span"><i>b</i></span> и <span class="tex-span"><i>c</i></span> вывести, какое максимальное значение выражения можно получить.</p></div><div
