Построение по минимумам</div><div class="time-limit"><div class="property-title">ограничение по времени на тест</div>2 секунды</div><div class="memory-limit"><div class="property-title">ограничение по памяти на тест</div>256 мегабайт</div><div class="input-file input-standard"><div class="property-title">ввод</div>стандартный ввод</div><div class="output-file output-standard"><div class="property-title">вывод</div>стандартный вывод</div></div><div><p>У мальчика Саши есть массив $$$a$$$ из $$$n$$$ целых чисел. Ему стало скучно, и для всех $$$i$$$, $$$j$$$ ($$$i < j$$$) он записал минимальное значение из $$$a_i$$$ и $$$a_j$$$. Он получил новый массив $$$b$$$ размером $$$\frac{n\cdot (n-1)}{2}$$$.</p><p>Например, если $$$a=$$$ [$$$2,3,5,1$$$], он запишет [$$$\min(2, 3), \min(2, 5), \min(2, 1), \min(3, 5), \min(3, 1), min(5, ваша задача — восстановить любой возможный массив $$$a$$$, из которого мог быть получен массив $$$b$$$.</p><p><span class="tex-font-style-bf">Элементы массива $$$a$$$ должны находиться в диапазоне
