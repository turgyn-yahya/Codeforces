Заменяй и суммируй</div><div class="time-limit"><div class="property-title">ограничение по времени на тест</div>2 секунды</div><div class="memory-limit"><div class="property-title">ограничение по памяти на тест</div>256 мегабайт</div><div class="input-file input-standard"><div class="property-title">ввод</div>стандартный ввод</div><div class="output-file output-standard"><div class="property-title">вывод</div>стандартный вывод</div></div><div><p>Сегодня у KQ экзамен в академии Граиля. Строгий учитель дал задачу, с которой KQ не смог справиться. Ему дали два массива $$$a$$$ и $$$b$$$ длины $$$n$$$. KQ разрешается выполнять следующие операции на массивах: </p><ul> <li> Выбрать индекс $$$i$$$ ($$$1\le i\lt n$$$) и заменить $$$a_i$$$ на $$$a_{i+1}$$$. </li><li> Выбрать индекс $$$i$$$ ($$$1\le i\le n$$$) и заменить $$$a_i$$$ на $$$b_i$$$. </li></ul> Теперь ему дали $$$q$$$ запросов. Каждый запрос описывается двумя числами $$$l$$$ и $$$r$$$. Его задача — для каждого запроса найти максимальное значение суммы $$$(a_l + a_{l+1} + a_{l+2} + \dots + a_r)$$$, если он может выполнить любое количество операций с любыми элементами массива. Поскольку он недостаточно умен для этого, он просит вас о помощи.</div><div class="input-specification"><div class="section-title">Входные данные</div><p>Каждый тест состоит из нескольких наборов входных данных. В первой строке находится одно целое число $$$t$$$ ($$$1\le t\le 10^4$$$) — количество наборов входных данных. Далее следует описание наборов входных данных. </p><p>Первая строка каждого набора входных данных содержит два целых числа $$$n$$$, $$$q$$$ $$$(1\le n, q\le 2 \cdot 10^5)$$$.</p><p>Вторая строка каждого набора входных данных содержит $$$n$$$ целых чисел $$$a_1, a_2,...,a_n$$$ $$$(1\le a_i\le 10^4)$$$.</p><p>Третья строка каждого набора входных данных содержит $$$n$$$ целых чисел $$$b_1, b_2,...,b_n$$$ $$$(1\le b_i\le 10^4)$$$. </p><p>Следующие $$$q$$$ строк содержат по два целых числа $$$l$$$ и $$$r$$$ $$$(1\le l\le r\le n)$$$.</p><p>Гарантируется, что сумма значений $$$n$$$ и сумма значений $$$q$$$ по всем наборам входных данных не превосходит $$$2 \cdot 10^5$$$.</p></div><div class="output-specification"><div class="section-title">Выходные данные</div><p>Для каждого набора
