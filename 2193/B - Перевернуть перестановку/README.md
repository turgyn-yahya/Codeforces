Перевернуть перестановку</div><div class="time-limit"><div class="property-title">ограничение по времени на тест</div>2 секунды</div><div class="memory-limit"><div class="property-title">ограничение по памяти на тест</div>256 мегабайт</div><div class="input-file input-standard"><div class="property-title">ввод</div>стандартный ввод</div><div class="output-file output-standard"><div class="property-title">вывод</div>стандартный вывод</div></div><div><p>Перестановкой длины $$$n$$$ является массив, состоящий из $$$n$$$ различных целых чисел от $$$1$$$ до $$$n$$$ в произвольном порядке. Например, $$$[2,3,1,5,4]$$$ является перестановкой, но $$$[1,2,2]$$$ и $$$[1,3,4]$$$ не являются перестановками.</p><p>Вам дана перестановка $$$p$$$ длины $$$n$$$. Вы можете сделать следующую операцию <span class="tex-font-style-bf">ровно один раз</span>: </p><ul> <li> Выберите два целых числа $$$l,$$$ $$$r$$$ ($$$1\le l\le r\le n$$$). </li><li> Переверните отрезок $$$[l, r]$$$ в перестановке $$$p$$$. </li></ul> Ваша задача — среди всех перестановок, которых можно получить, сделав операцию, вывести лексикографически максимальную. Перестановка $$$a$$$ лексикографически больше перестановки $$$b$$$, если для первой позиции $$$i$$$, где они различаются, выполняется $$$a_i\gt b_i$$$.</div><div class="input-specification"><div class="section-title">Входные данные</div><p>Каждый тест состоит из нескольких наборов входных данных. Далее следует описание наборов входных данных.</p><p>Первая строка каждого набора входных данных содержит число $$$n$$$ ($$$1\le n\le 2\cdot 10^5$$$).</p><p>Вторая строка каждого набора входных данных содержит $$$n$$$ различных целых чисел $$$p_1, p_2,...,p_n$$$ $$$(1\le p_i\le n)$$$.</p><p>Гарантируется, что сумма значений $$$n$$$ по всем наборам входных данных не превосходит $$$2\cdot 10^5$$$.</p></div><div class="output-specification"><div class="section-title">Выходные данные</div><p>Для каждого набора входных данных выведите лексикографически максимальную перестановку, которую
