<div class="header"><div class="title">C. Двусторонние строки</div><div class="time-limit"><div class="property-title">ограничение по времени на тест</div>2 секунды</div><div class="memory-limit"><div class="property-title">ограничение по памяти на тест</div>256 мегабайт</div><div class="input-file input-standard"><div class="property-title">ввод</div>стандартный ввод</div><div class="output-file output-standard"><div class="property-title">вывод</div>стандартный вывод</div></div><div><p>Вам заданы строки $$$a$$$ и $$$b$$$, состоящие из строчных букв латинского алфавита. Вы можете сделать произвольное число следующих операций в произвольном порядке: </p><ul> <li> если $$$|a|  \gt  0$$$ (длина строки $$$a$$$ больше нуля), удалить первый символ строки $$$a$$$, то есть заменить $$$a$$$ на $$$a_2 a_3 \ldots a_n$$$; </li><li> если $$$|a|  \gt  0$$$, удалить последний символ строки $$$a$$$, то есть заменить $$$a$$$ на $$$a_1 a_2 \ldots a_{n-1}$$$; </li><li> если $$$|b|  \gt  0$$$ (длина строки $$$b$$$ больше нуля), удалить первый символ строки $$$b$$$, то есть заменить $$$b$$$ на $$$b_2 b_3 \ldots b_n$$$; </li><li> если $$$|b|  \gt  0$$$, удалить последний символ строки $$$b$$$, то есть заменить $$$b$$$ на $$$b_1 b_2 \ldots b_{n-1}$$$. </li></ul><p>Заметьте, что после каждой из операций строка $$$a$$$ или $$$b$$$ могут стать пустыми.</p><p>Например, если $$$a=$$$<span class="tex-font-style-tt">«hello»</span> и $$$b=$$$<span class="tex-font-style-tt">«icpc»</span>, то вы можете применить следующую последовательность операций: </p><ul> <li> удалить первый символ строки $$$a$$$ $$$\Rightarrow$$$ $$$a=$$$<span class="tex-font-style-tt">«ello»</span> и $$$b=$$$<span class="tex-font-style-tt">«icpc»</span>; </li><li> удалить первый символ строки $$$b$$$ $$$\Rightarrow$$$ $$$a=$$$<span class="tex-font-style-tt">«ello»</span> и $$$b=$$$<span class="tex-font-style-tt">«cpc»</span>; </li><li> удалить первый символ строки $$$b$$$ $$$\Rightarrow$$$ $$$a=$$$<span class="tex-font-style-tt">«ello»</span> и $$$b=$$$<span class="tex-font-style-tt">«pc»</span>; </li><li> удалить последний символ строки $$$a$$$ $$$\Rightarrow$$$ $$$a=$$$<span class="tex-font-style-tt">«ell»</span> и $$$b=$$$<span class="tex-font-style-tt">«pc»</span>; </li><li> удалить последний символ строки $$$b$$$ $$$\Rightarrow$$$ $$$a=$$$<span class="tex-font-style-tt">«ell»</span> и $$$b=$$$<span class="tex-font-style-tt">«p»</span>. </li></ul><p>По заданным строкам $$$a$$$ и $$$b$$$ найдите минимальное количество операций, за которые можно сделать строки $$$a$$$ и $$$b$$$ равными. Обратите внимание, что пустые строки также являются равными.</p></div><div class="input-specification"><div class="section-title">Входные данные</div><p>В первой строке содержится одно целое число $$$t$$$ ($$$1 \le t \le 100$$$). Далее следуют $$$t$$$ наборов входных данных.</p><p>Первая строка каждого набора входных данных содержит строку $$$a$$$ ($$$1 \le |a| \le 20$$$), состоящую из строчных букв латинского алфавита.</p><p>Вторая строка каждого набора входных данных содержит строку $$$b$$$ ($$$1 \le |b| \le 20$$$), состоящую из строчных букв латинского алфавита.</p></div><div class="output-specification"><div class="section-title">Выходные данные</div><p>Для каждого набора входных данных выведите одно число — минимальное количество операций, за которые можно сделать строки $$$a$$$ и $$$b$$$ равными.</p></div><div class="sample-tests"><div class="section-title">Пример</div><div class="sample-test"><div class="input"><div class="title">Входные данные<div title="Скопировать" data-clipboard-target="#id004493000318882667" id="id002854733633690183" class="input-output-copier">Скопировать</div></div><pre id="id004493000318882667">5
